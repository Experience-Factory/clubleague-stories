# Club League Stories (EF Eupen)

Mini-app mobile pour créer les stories Instagram **Podium of the week** et **Driver of the night** d'Experience Factory Eupen.

Lien pour le personnel : https://experience-factory.github.io/clubleague-stories/

- Les photos restent sur le téléphone : rien n'est envoyé sur un serveur.
- Pas de photo = le pilote ne souhaite pas apparaître : un casque s'affiche à la place.

`index.html` est généré, ne pas le modifier à la main (source : `template.html` + `build.py`, gérés en local).
